Container Stowage Intelligence

BAPLIE EDI Parser

Parses BAPLIE 2.1 and 3.0 EDI messages — container position, weight, hazmat class, refrigeration status, and stowage instructions.

🗺️

2D/3D Bay Plan Viewer

Interactive 3D vessel visualisation — click any container to see its details, weight distribution, and adjacent unit information.

⚖️

Ship Stability Calculations

GM, KG, displacement, trim, and list calculations — real-time stability assessment as containers are loaded or discharged.

Cargo Manifest API

REST and GraphQL endpoints for manifest data — integrates with customs, terminal, and shipping line systems.

⚠️

Hazmat Segregation

IMDG code compliance checking — ensures dangerous goods are correctly stowed with proper segregation distances.

📊

Weight Distribution

Longitudinal and transverse weight distribution visualisation — stress diagram and shear force analysis for voyage planning.
