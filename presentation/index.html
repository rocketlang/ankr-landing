The Problem

At scale, interpretation becomes hallucination.

When you run two hundred services, no human and no model can reliably infer what each one can do. Every guess about a capability is a guess that can be wrong — and a wrong guess at scale is indistinguishable from a lie.

How Binary Truth Works

Three layers. Declaration, index, proof.

Every service declares exactly what it knows — no inference anywhere in the chain. The registry returns the whole universe in one query. And authorization is a bit test, not a lookup.

ForjaDeclaration
STATE + TRUST + SENSE + PROOF. A service declares precisely what it can answer and do. No inference — the manifest is the truth.
AnkrCodexIndex
A centralised capability registry. One query returns the full map of ~290 services across the universe.
Trust BitmaskEncoding
A 32-bit integer per service. (mask & BOOK) !== 0 is proof, not a lookup — O(1) capability authorization across the mesh.
