One line. Every device.

Installs Claude Code, the ANKR harness (guard rails that refuse the classic disasters, in plain English), a bring-your-own-key page and the IDE link. Made for a person who has never coded. Re-running the line updates; it never resets.

You pay Anthropic (or the provider you choose). ANKR receives nothing — not your key, not a bill, not a sign-up.

Pick your device above.

Windows

  1. Press the Windows key, type PowerShell, press Enter. A blue or black window opens.
  2. Press Copy below, then right-click inside the PowerShell window to paste, and press Enter.
  3. Follow the lines that appear. A browser page called Your key, your computer opens near the end; choose the option that is true for you.
irm https://ankr.in/install/install.ps1 | iex

You should see lines starting with == 1/6 Git for Windows … == 6/6 doctor, each with ✓ marks, a browser page for your sign-in, and finally All checks passed.

If not — "irm is not recognized": this is an old Windows (7 or 8) without a modern PowerShell; the WSL route below will not work there either — ask for help. Red text mentioning winget: open the Microsoft Store, install App Installer, then paste the line again. "running scripts is disabled": the line runs in memory and needs no policy change; close the window, open PowerShell again as yourself (not as administrator) and paste again. Anything else: the line prints the fix after each ✗ — read it, do it, paste the line again.

Prefer Ubuntu inside Windows? optional · what the founder uses with VS Code

This installs Ubuntu (WSL), VS Code with its Remote-WSL extension, and then runs the Mac / Linux line inside Ubuntu.

& ([scriptblock]::Create((irm https://ankr.in/install/install.ps1))) -WSL

You should see Windows installing Ubuntu and asking to restart. After the restart, open the Ubuntu app, choose a username and password when it asks, and paste the Mac / Linux line below there. Then in VS Code: bottom-left >< → Connect to WSL → Terminal → type claude.

If not — if Ubuntu was already there, the line skips the restart and runs straight through; if the Ubuntu window asks for a password it does not show what you type — that is normal.

Mac / Linux

  1. Open a terminal. Mac: press ⌘ Space, type Terminal, Enter. Ubuntu: press Ctrl Alt T. Inside Windows (WSL): open the Ubuntu app.
  2. Press Copy below, paste into the terminal, press Enter.
  3. Follow the lines. A browser page called Your key, your computer opens near the end; choose the option that is true for you.
curl -fsSL https://ankr.in/install/install.sh | bash

You should see ANKR install · linux (or macos / wsl), then == 1/6 prerequisites … == 6/6 doctor with ✓ marks, the sign-in page, and finally All checks passed.

If not — "curl: command not found" (Ubuntu/Debian): run sudo apt-get install -y curl and paste the line again. Mac shows a window about "command line developer tools": click Install, wait until it finishes, paste the line again. It asks for a password: that is your own Mac or Linux password; nothing shows while you type. "claude is not on PATH": close the terminal, open a new one, paste the line again.

Android

A · Run it on the phone (Termux) how the founder works while being driven

Claude Code has no Android build: the npm package carries Linux, macOS and Windows binaries only ❝ npm registry, read 12 Sep 2026, and Anthropic's documentation does not list Android ∅. So the line installs Ubuntu inside Termux (proot-distro) and runs Anthropic's own Linux installer there. This route ran end to end in a Termux container on 12 Sep 2026 ⊕; a real phone is the next test. If it fails on yours, use route B.

  1. Install Termux from F-Droid or from the Termux project's GitHub releases — the Termux project itself says the Google Play copy is not the maintained build ❝ termux-app. On Xiaomi/Redmi (MIUI) you may have to allow "install from this source" for your browser or F-Droid.
  2. Open Termux. Paste the first line, Enter, wait; then the second line, Enter.
pkg install -y curl
curl -fsSL https://ankr.in/install/install.sh | bash

You should see ANKR install · termux, then Android: Claude Code runs inside Ubuntu-in-Termux, a few minutes while Ubuntu downloads, then the six stages running inside Ubuntu with ✓ marks, and the sign-in page's address printed as BYOK page: http://127.0.0.1… — open it in your phone's browser. Afterwards, in Termux, type claude: it hands over to Ubuntu. Your projects live in Ubuntu's home folder. Two short lines on purpose: long pasted lines get wrapped and mangled in Termux.

If not — "pkg: command not found": you are not inside Termux. "Unable to locate package": run pkg update once, then the two lines again. The Ubuntu download fails: run proot-distro install ubuntu by hand and read what it says, then the second line again. The page does not open by itself: that is expected inside Ubuntu — copy the printed link into your browser, or in Claude type /ankr-byok later.

What the line does

  • Claude Code — installed by Anthropic's own installer (claude.ai/install.sh / install.ps1), which keeps itself up to date ❝ docs. On Termux, through npm. Nothing is mirrored or repackaged by ANKR.
  • Windows only: Git for Windows first, because Claude Code runs its hooks through Git Bash there ❝ docs. If Git cannot be installed, the hooks are not registered and the line says so.
  • The ANKR harness into ~/.claude: a short rules file Claude reads in every project (compute / quote / null, add what you changed, verify before "done"), a guard hook that refuses git add ., git stash, git clean, git reset --hard, git push --force, rm -rf /, prisma db push, DROP TABLE and friends with the reason in plain English, a session brief, and two commands inside Claude: /ankr-doctor and /ankr-byok.
  • Your existing settings are kept. The line backs up settings.json to a dated copy, merges by content, and adds one import line to CLAUDE.md. If your settings file is not valid JSON it refuses to touch it and tells you.
  • IDE: if VS Code is on the machine, the Anthropic.claude-code extension is added (on Windows the line can install VS Code too) ❝ docs. JetBrains users: the plugin is "Claude Code" in the marketplace ❝ docs.
  • The doctor at the end prints one line per check — ✓, or ✗ with the fix beside it.

Your key stays with you

The page that opens at the end lives on your own computer (127.0.0.1). Three choices:

  • I pay Anthropic for Claude (Pro or Max) — no key. You type claude and sign in on Anthropic's own page. A free claude.ai account does not include Claude Code ❝ docs.
  • I have an Anthropic API key — pasted there, checked once against api.anthropic.com if you leave the tick on, then written to ~/.claude/settings.json and nowhere else ❝ docs.
  • Another provider that speaks Anthropic's API — a URL and a token, saved as-is and marked unverified.

One button removes it. ANKR never sees it. This is the whole model: ANKR built the guard rails once; you pay for what you use, directly, to the provider you chose.

Later

  • Update: run the same line again. It replaces the harness files and keeps everything of yours.
  • Check: inside Claude type /ankr-doctor. Change sign-in: /ankr-byok.
  • Opt out: delete the one import line in ~/.claude/CLAUDE.md and the two ankr hook entries in settings.json; the backups are beside the file.
  • From your phone: on the laptop, claude remote-control; in the Claude app, the Code tab.
